# 祁昼悬浮状态栏 · 掌心窗 0.3.8.11

这是基于你现有 0.3.8.10 的更新安装包。直接覆盖安装，保留掌心窗数据；不要先卸载旧版。

## 安装顺序

1. 将 `qizhou-status-overlay-v5.sh` 上传到原来运行状态栏的服务器。用原来的账户执行：

   ```bash
   bash qizhou-status-overlay-v5.sh /home/ubuntu/qizhou-status-widget
   ```

   如果项目在其他位置，把后面的路径改成实际路径。脚本要求当前已安装紧凑版 v4，会自动备份、检查语法、重启 `qizhou-status` 并验证；新进程健康检查失败会恢复本次备份。不会重启隧道。

2. 手机上打开 `Zhangxinchuang-public-v0.3.8.11.apk`，覆盖安装。
3. 掌心窗 → 设置 → 权限与运行 → **祁昼悬浮状态栏**。粘贴「状态栏1」原来的完整 HTTPS MCP 地址，再点保存并开启。地址格式是 `https://你的域名/mcp/私密密钥`，无需另建地址或填写新的密钥。
4. 按提示允许掌心窗显示悬浮窗和通知。手机系统里给掌心窗允许自启动，电池策略设为不限制。不同手机的菜单名称可能不同。
5. 返回 ChatGPT，聊天页面照常使用。拖动状态栏标题调整位置；`−` 折叠为小条，`+` 展开，`×` 关闭。通知也能进入设置或关闭状态栏。

## 这版的行为

- 展开高度 188dp，约为原大卡片的三分之二；折叠高度 44dp。
- 悬浮窗仅占卡片范围、不获取键盘焦点，卡片外操作交给当前应用。系统键盘位于悬浮窗之上。
- 亮屏且解锁时约每 5 秒读取一次现有状态；没有新状态时继续显示上一次数据。聊天中的状态同步工具负责更新服务端。
- 原聊天卡片的互动功能保留；手机悬浮栏提供状态显示、拖动、折叠和关闭。
- 断线自动重试，间隔逐步增加到最多 60 秒；切换网络会尽快重试。显示缓存时明确提示暂未同步。
- 熄屏或锁屏隐藏卡片并暂停网络轮询；解锁后恢复。状态和窗口位置保存在本机，缓存不会每 5 秒重复写盘。
- 单独使用前台服务，并提供运行通知。系统允许时进程回收后自动恢复；已开启的状态栏在正常重启手机或更新应用后尝试恢复。用户主动关闭后不会自行重开。
- 强行停止应用、厂商后台管制、撤回权限可能终止服务。重新打开掌心窗可尝试恢复；无法承诺任何 Android 手机永不杀后台。

## 手机验收

1. 返回 ChatGPT 连续发消息、拉出键盘、滚动聊天，确认操作正常。
2. 更新一次状态，通常 5 秒左右在悬浮栏看到变化。
3. 断网再联网，确认先提示暂未同步，随后恢复。
4. 锁屏再解锁，确认卡片回来；关闭状态栏后再开掌心窗，确认没有自行重开。
5. 使用一晚后再看后台；手机重启后检查恢复。如果被系统限制，保留机型、系统版本和现象继续排查。

这次已通过 APK 编译和原签名验证；接口验证包括无密钥拒绝、只读轮询、缓存协商、状态变化、损坏状态恢复、原 MCP 初始化和安装回退。聊天键盘、厂商省电策略以及整夜运行仍需你的手机实测。

## 回退服务器

```bash
bash qizhou-status-overlay-v5.sh /home/ubuntu/qizhou-status-widget --rollback
```

手机上关闭悬浮状态栏即可继续使用掌心窗原功能。不要通过卸载应用来回退，以免丢失本地日记。
