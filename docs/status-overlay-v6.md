# 悬浮状态栏 v6 · 掌心窗 0.3.8.12

## 先说明状态的范围

同一个 MCP 地址对应同一份状态。手机、电脑和不同聊天调用该地址时会共用它，后写入的内容可能覆盖前面的内容。聊天记忆并不实时互通，当前对话也不会自动知道其他对话发生了什么。

本次更新只识别 ChatGPT 应用前台，不能识别某个账号或某一条对话。卡片上标有“共用”。它也不会嵌入官方客户端内部。若希望每条对话有独立状态，需要另外设计频道和明确绑定。

## 安装

1. 将 `qizhou-status-overlay-v6.sh` 上传原服务器，用原来的账户执行：

   ```bash
   bash qizhou-status-overlay-v6.sh
   ```

   这是从已安装的 v5 升级到 v6；支持自动查找原项目。未找到时，在命令后加实际项目目录，例如 `/home/ubuntu/qizhou-status-widget`。

2. 用 `Zhangxinchuang-public-v0.3.8.12.apk` 覆盖安装掌心窗。不要卸载旧版。原 MCP 地址和本地数据会保留。
3. 确认手机已开启掌心窗的无障碍权限。进入掌心窗 → 设置 → 权限与运行 → 祁昼悬浮状态栏 → 保存并开启，然后返回 ChatGPT。

## 更新内容

- 只在官方 ChatGPT 应用前台时显示，切换到其他应用会自动隐藏。无法确认当前应用或无障碍服务断开时也会隐藏。识别窗口所属应用，不新增读取聊天内容的逻辑。
- 打字时会跳过输入法窗口，避免键盘出现就把状态栏隐藏。
- 恢复靠近、摸摸、刷新。摸摸后显示服务器原有的部位选项，再点选执行。部位面板复用原卡片空间，展开高度保持 188dp；点击“摸摸”可返回状态。
- 触碰会更新服务器上的共用状态和卡片反应。原生悬浮窗无法自动向 ChatGPT 当前对话发送消息；需要你发消息后才有聊天回复。
- 操作发送期间禁用按钮，不自动重发操作。服务器短时间内对同一操作编号去重，连续点击过快会限流；请求超时会提示先刷新确认结果。
- 保留拖动、折叠、关闭、熄屏暂停、断线重连和缓存。

## 验收

已通过编译、签名校验，以及真实 HTTP 接口的读取、验证、更新、输入校验、重复操作去重和限流检查。安装脚本支持重复运行与回退。

手机上还需实测：ChatGPT → 桌面 → 其他 App → ChatGPT 的显隐；打字键盘；摸摸操作；无障碍服务关闭后是否隐藏。各厂商的后台和窗口行为无法仅凭编译保证。

服务器回退到 v5：

```bash
bash qizhou-status-overlay-v6.sh ~/qizhou-status-widget --rollback
```
